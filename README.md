# VOW

An experimental collection of cinematic wedding websites built around motion,
editorial typography, immersive visuals, and expressive RSVP experiences.

## Templates

- **Afterglow** — cinematic, warm, and customizable
- **Glasshouse** — botanical and luminous
- **Electric Vow** — kinetic and unapologetic
- **Aeterna** — restrained luxury editorial
- **今夕** — contemporary Chinese typography, paper, ink, and red thread
- **合卺** — tactile Chinese ceremony, handwritten marks, paper, and tree shadows
- **此刻** — modern Chinese typography for a Western-style city wedding
